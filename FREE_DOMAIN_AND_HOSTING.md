# Free Domain And Hosting Plan

You can publish this Devel-Hub website without paying by using GitHub Pages.

## Free URL Option

GitHub Pages gives you a free address like:

```text
https://your-github-username.github.io/devel-hub/
```

This is not a paid custom domain, but it is a real public website link and costs nothing.

## What To Do

1. Create a free GitHub account if you do not already have one.
2. Create a public repository named `devel-hub`.
3. Upload these files:
   - `index.html`
   - `styles.css`
   - `script.js`
4. In the repository, open `Settings`, then `Pages`.
5. Set the source to `Deploy from a branch`.
6. Choose the `main` branch and `/root` folder.
7. Save.

GitHub will show your free website URL after the site is published.

## Important Contact Step

Before publishing, open `script.js` and replace:

```js
const contactEmail = "your-email@example.com";
```

with your actual email address so client enquiries reach you.

## About Custom Domains

A custom domain like `develhub.com` or `devel-hub.in` usually costs money every year. To avoid spending anything, use the free GitHub Pages URL first.
